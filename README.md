# 陀螺盲盒系统

抽盲盒形式的学习激励系统。目标：UX-20 战斗陀螺（¥1550），约 3 个月达成，月支出锁在 ¥500 以内。

线上地址：https://claude.ai/code/artifact/b11f82ba-322d-4132-b5b0-8d356be42dd8
（家长 PIN 预设 `2020`，进入设置可改。）

---

## 一、经济模型

### 1. 八级阶梯：3 个换 1 个

| 等级 | 铜当量 | 折合金额 |
|---|---|---|
| 铜陀螺 | 1 | ¥0.71 |
| 银陀螺 | 3 | ¥2.13 |
| 金陀螺 | 9 | ¥6.4 |
| 铂金陀螺 | 27 | ¥19 |
| 钻石陀螺 | 81 | ¥57 |
| 绿宝石陀螺 | 243 | ¥172 |
| 红金陀螺 | 729 | ¥517 |
| **终极陀螺** | **2187** | **¥1550 = UX-20** |

原方案 8 级按 5:1 是 5⁷ = 78,125 铜当量 ≈ ¥19 万，不可能。**把比例从 5 改成 3，八级就正好落在 2187 ≈ ¥1550。**

**核心不变量：1 铜当量 = ¥0.709。** 任何奖品都能用它定价，预算永远算得清。

### 2. 概率（每盒 5 分）

| 结果 | 概率 | 铜当量 |
|---|---|---|
| 铜 | 88% | 1 |
| 银 | 9.6% | 3 |
| 金 | 2% | 9 |
| 铂金 | 0.32% | 27 |
| 钻石 | 0.08% | 81 |

期望 **1.50 铜当量/盒**。绿宝石以上只能靠合成，抽不到——所以运气再好也不会瞬间通关。

保底两条：
- **十连保底**：一次十连全是铜时，最后一个升为银
- **铂金保底**：连续 400 盒没出铂金则必出

### 3. 积分与消耗

积分表不变，加两条护栏：

| 数学 | 分 |  | 英文 | 分 |
|---|---|---|---|---|
| 2 分钟影片 | 1 | | 1 个单词 | 1 |
| 简单题 | 1 | | 1 个语法点 | 20 |
| 中等题 | 2 | | 口说 5 分钟 | 2.5 |
| 困难题 | 4 | | 听力 5 分钟 | 2.5 |
| | | | 阅读 5 分钟 | 2.5 |

- **每盒 5 分**（十连 50 分）
- **每日上限 90 分 / 每月上限 2300 分** ← 预算闸门
- 2 小时/天大约产出 80–90 分 ≈ 每天 16 盒 ≈ 1.6 次十连

### 4. 模拟结果（4000 次蒙特卡洛，每天 84 分）

| | |
|---|---|
| 中位数 | **93 天（3.10 个月）** |
| 80% 区间 | 85 – 97 天 |
| 开盒数（中位） | 约 1,420 盒 |

盒子便宜、数量大，大数定律生效，工期比 60 分一盒时**更稳**（原方案 80% 区间是 77–112 天）。

### 5. 预算为什么锁得住

1. **实物只有一件。** 运气只影响日期，不影响金额——总支出恒为 ¥1550。
2. **月上限 2300 分 = 每月最多 460 盒 ≈ 690 铜当量 ≈ ¥489/月**，低于 ¥500 额度。
3. ¥1550 ÷ ¥500/月 = 3.1 个月——预算和工期天然吻合，中间不能再塞别的实物奖。

**中途奖励建议用零成本的：** 多 30 分钟游戏时间、周末活动他挑、免作业券。想给实物就按 ¥0.71/铜当量 从收藏架扣陀螺（设置里「手动调整」），金额自动可控。

## 二、界面：孩子看到什么

孩子端**不显示**价格、完成度百分比、铜当量、预计还需多少天。取而代之：

- **进度条**：只有形状，没有数字；三段刻度 = 集齐 3 个红金陀螺
- **三个数字**：已开盒 / 最高纪录 / 图鉴 N/8
- **下一步**：「再 2 个铜陀螺 → 银陀螺」，永远给一个够得着的目标
- **收藏架**：八级全列出来，没解锁的是暗色剪影——看得见还有什么在上面

所有真实数字（概率、期望、金额、月支出上限）都在家长设置里。

## 三、部署到 Netlify

```bash
git init && git add -A && git commit -m "陀螺盲盒"
git remote add origin git@github.com:<你的账号>/beyblade-boxes.git
git push -u origin main
```

然后到 Netlify → **Add new site → Import an existing project**，选这个仓库。构建设置已经写在 `netlify.toml` 里，直接 Deploy 就行：

| | |
|---|---|
| Build command | `node build.js` |
| Publish directory | `site` |
| Functions | `netlify/functions`（自动识别） |

### 后端

`/api/state` 是一个 Netlify Function，用 **Netlify Blobs** 存进度——站点自带的键值存储，不用另开数据库、不用付费方案。

- `GET` 拿当前进度
- `PUT` 写入；带的 `seq` 比服务器旧会返回 `409` + 服务器版本，页面自动同步到最新（两台设备同时开盒不会互相覆盖）
- `DELETE` 清空

### 加把锁（建议做）

默认任何人拿到网址都能改进度。到 Netlify → **Site configuration → Environment variables** 加一个 `BB_KEY`，值自己取一串字符。之后：

- 家长在页面「设置 → 同步与备份 → 同步密钥」里填一次，存在浏览器里
- 或者直接开 `https://你的站点.netlify.app/#k=你的密钥`，页面读完会自动把它从地址栏抹掉

没填对密钥的设备变成只读，进度只留在本机。

### 存储怎么选

页面开机时自己判断，家长设置里能看到当前用的是哪个：

| 打开方式 | 存储 |
|---|---|
| Claude Artifact | Artifact 云端（页面发布自己的新版本） |
| Netlify / 任何 http(s) 站点 | `/api/state` 后端，跨设备同步 |
| 双击本地 html、后端挂了、密钥不对 | 本机 localStorage |

三种情况页面都能正常玩，区别只是同不同步。设置里的**导出备份 / 导入备份**是纯文字 JSON，任何情况下都能搬家。

## 四、开发

```
src/app.template.html   # 唯一源文件（含 __TPL_B64__ / /*__STATE__*/null 两个占位符）
build.js                # 一次生成两个产物
dist/index.html         # Artifact 片段（内嵌 base64 模板，能自我发布）
site/index.html         # Netlify 独立页面（无 base64，小一半）
netlify/functions/state.mjs
seed.json               # 可选：重建时把线上已有进度带过来，避免发布覆盖
```

```bash
node build.js
```

Artifact 版通过 `claude.use("artifact")` 把新版本发布回自己来保存进度。`publish()` 要求完整文档，而 Artifact 工具收的是 body 片段——所以片段里用 base64 存了一份**保留占位符的完整文档模板**，每次保存时从它重新拼出下一版。模板因此是自己的不动点。Netlify 版不需要这套，`build.js` 把那份 base64 留空。

改经济模型后重新发布 Artifact 会覆盖线上状态：先从线上读回当前 `EMBEDDED`，把要保留的字段写进 `seed.json` 再 build。**状态结构变了就升 `VER`**，`migrate()` 见到对不上的版本号直接重开一局——这也是「全部重置」最省事的做法。
